Dann häng diesen Absatz zusätzlich an:

Die Umgebung ist frisch. Bitte richte sie zuerst ein:

    cd backend
    cp .env.example .env      # .env fehlt immer, sie ist gitignored
    uv sync                   # legt .venv an (nicht im ZIP enthalten)
    docker compose up -d db   # oder lokales Postgres
    uv run alembic upgrade head
    uv run pytest -q

Ohne Docker-Daemon: Postgres lässt sich per apt installieren und mit
initdb/pg_ctl als Benutzer "postgres" starten. Steht in HANDOFF.md unter
"Stolperfallen dieser Umgebung".
